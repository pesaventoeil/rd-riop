## What was actually wrong

1. **`BT_FUSE_SEL` burn is NOT needed. Drop it.** NXP's RIOP getting-started guide sets SW6 to 1:OFF 2:ON 3:OFF 4:OFF, which is the same `100` the LabJack drives. Stock boards boot Port-B NOR in that mode with fuses as-is. The "100 = Port A, so no strap can boot" conclusion (G11) was wrong for this board.
2. **The "cold boot" tests were not cold.** The flashloader (and LinkServer's `B_MXIC_OPI` driver) leaves the MXIC in OPI mode. PowerTail only cuts 24V; USB and the probe keep the flash powered, so the ROM's SPI-mode FCB read failed and fell back to serial download. That explains SPT0 / G7 / G8 / G10. "SFDP 0B" means "flash is in OPI", not a wedge.
3. **`.3` was never going to answer.** The EIP app runs DHCP (`goal_eipCfgDhcpOn(GOAL_TRUE)`), and the full flash erase wiped any stored IP config. Earlier "`.3` unreachable" results under the debugger may have had the same cause.

Leave state is probe **unplugged**. Prefer automation; do not ask Daniel for a true cold cycle by default.

1. **Preferred after SPT/OPI flashloader** (probe already out): LabJack PowerTail via `ljpower.py cycle 10 --requester cursor`. Proven on HEAD gate=0 (ListIdentity + red LED + Class 1) and on the `6410533` rebuild after an earlier true cold boot.

## Rules going forward

- **Flash only with the SPT/flashloader flow above** (or a merged image that contains this same OPI FCB). Do **not** program with LinkServer's QSPI/OPI drivers or in-image FCBs. Do **not** set `XIP_BOOT_HEADER_ENABLE=1`.
- After flash: **PowerTail first** when the probe is out; true cold cycle only if ListIdentity fails. See “Accepted power-cycle methods” above.
- Stop the debugger-skip work (`Prepare_CM7` / `flexspi_init`). Those hangs only happen when the ROM never handed off.
- Board IP is **DHCP on the office LAN**. Either look it up each time with `eip_list_identity.py`, or set it static (via EIP TCP/IP object or a code change) before relying on `.3`. Note that EIP multicast and Class 1 traffic is now on the office network; consider isolating ETH4.
