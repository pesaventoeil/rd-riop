# Changelog OpENer

## Changes introduced by port GmbH

### V2.20.0 (2019-05-07)
  * improved randomness of delayed Encapsulation messages
  * still enable DLR Beacon Forwarding even if DLR is disabled to protect device
  * fixed handling of empty or invalid encapsulation requests

### V2.19.0 (2019-03-19)
  * fixed old timeout state still active after reset
  * fixed management of Ethernet link states
  * fixed LED behavior if dynamic IP was lost due to Phy reconfiguration
  * fixed buffer leak for NOP commands
  * changed error logs regarding external data to warnings
  * reset volatile attributes on Reset service

### V2.18.0 (2019-02-18)
  * fixed cleanup of encapsulation session if closed remotely
  * avoid unnecessary Phy configuration during startup
  * removed Time tick variable, stack uses timestamps instead
  * reworked CIP object model to reduce footprint and increase flexibility

### V2.17.0 (2019-01-30)
  * improved handling of encapsulation sessions
  * added General Status Code to API for requests handling of Virtual Classes
  * support NULL ForwardOpen requests
  * improved management of CIP classes (less memory required)

### V2.16.0 (2019-01-08)
  * fixed allocation of encapsulation session resources
  * fixed calculation of ProductionTriggerTimeout for cyclic connections
  * reduced size of internal connection management data
  * use correct error code if ProductionInhibitTime > RPI
  * increased resolution of cyclic transmission trigger timer

### V2.15.0 (2018-12-06)
  * USer MAnual: added introduction to EtherNEt/IP

### V2.14.0 (2018-11-22)
  * fixed check of disabling Admin State of last active port
  * fixed LED behavior for Class 3 timeouts
  * fixed LED behavior after loosing dynamic IP address by all links down
  * release CLass 3 retransmission buffer after connection is closed
  * improved handling of fragmented encapsulation requests
  * fixed takover of mew producing multicast connection if old one is closed
  * extended API: goal_eipAssemblyObjectWrite() and goal_eipAssemblyObjectRead()
  * set default tick to 1 ms

### V2.13.0 (2018-10-01)
  * version number now follows GOAL version number
  * updated GOAL EIP wrapper for uC2C
  * added LED handler for NS & MS LEDs
  * support consuming multicast connections
  * fixed sending of multicast messages on multihoming devices
  * removed hard target reset, reset is now always simulated

### V2.3.1 (2018-05-22)
  * fixed handling of default IP address if no DHCP is enabled

### V2.3.0 (2018-05-05)
  * several bug fixes for Conformance Test CT-15
  * global Variables replaced by instance data
    (multiple instances of EIP stack possible)
  * dynamic configuration of stack during startup
  * made TCP/IP attributes TTL & Mcast Config settable
  * fixed responses to LargeForwardOpen Service requests
  * 

### V2.2.0 (2017-10-24)
  * implemented new NET API of GOAL
  * replaced IApp_SendUDPData() by opener_NWHsend()
  * added new config macro OPENER_CIP_NUM_IMPLICIT_CONNS for reserving UDP sockets
  * removed obsolete config macro OPENER_CIP_NUM_TCP_CONNS
  * support data types REAL (float) and LREAL (double)

### V2.1.0 (2017-05-02)
  * added API function CIP_CM_initConnectionId() to feed connection Id to Connection Manager
  * added API function CIP_TCPIP_updateIP() to update IP addresses of TCP/IP interface
  * improved check of incoming IO data if it belongs to an active connection
  * added API isConnectionActive() to check for any active connection
  * only set TCP/IP Interface attributes 3 or 5 if no connection is active
  * support multiple CIP Requests in one TCP data chunk
  * added processing of special requests after response was sent
    * IP address configuration update
    * Phy configuration update
    * device reset
  * change to IP address configuration takes now effect without a reset
  * TCP/IP Interface: o not check for active connections when changing IP configuration
  * GOAL: reissue DHCP requests after all links went down
  * API function IApp_RunIdleChanged() now indicates connection points to identify connection
  * added Ethernet Interface attribute 9 "Admin State"
  * changed behavior of IApp_getEthAttributes() to indicate requested attribute
  * added Ethernet Link attributes 12 "HC Interface Counters" & 13 "HC Media Counters"
  * fixed endian conversion functions for 64 bit integers
  * Ethernet Link objects support Gbit Phys
  * fixed response of Ethernet Link service "GetAttributeAll"
  * GOAL: updated platform files to newest API
  * added Connection Manager attributes 1 to 8
  * allocate connection lists dynamically during start up
  * new API functions for Creating CIP connections during start up:
    * addExclusiveOwnerConnection()
    * addInputOnlyConnection()
    * addListenOnlyConnection()
  * use same socket for producing and consuming IO data
  * fixed checking & error responses for mismatching ForwardOpen requests that
    contain an already opened producing multicast connection
  * added wrapper functions for accessing OpENer with the unified GOAL API for EtherNet/IP
  * added support for Virtual CIP classes
    * Virtual CIP classes are registered by application via registerVirtualClass()
    * OpENer passes all requests for a virtual class to application
    * application must generate CIP response
  * added API functions getFirstExclusiveOwnerEndpoint() & setFirstExclusiveOwnerEndpoint()
    to manipulate connection endpoints (Assembly IDs) of first Exclusive Owner connection
  * removed API function IApp_HandleApplication()
  * GOAL: updated to newest version

### V2.0.0 (2016-03-01)
  * added Ethernet Link attribute 11 "Interface Capability"
  * simplified API for accessing TCP/IP interface attributes: IApp_getTCPIPAttributes()
  * use own socket address structs and macros instead of BSD socket API
    (increases platform independence)
  * added support for for reading/writing big endian integers from/to buffer
  * created common include header "opener_includes.h"
  * close socket if all its connections timed out
  * fixed check of Encapsulation sequence Id of first received IO packet
  * fixed responses to Message Router services "GetAttributeSingle" & "GetAttributeAll"
  * GOAL: updated API to newest version


### V1.4.0 (2016-02-24)
  * Identity object service "Reset" supports parameter 2
    (Factory Reset without reset of communication configuration)
  * use Originator's IP address to determine connection owner
  * only use new DSCP values of QoS Object after reset for priorities
  * TCP/IP Interface attribute 5 is only settable, if Configuration Method is static
  * added Ethernet Link attribute 6 "Interface Control"
  * GOAL: initialize Phys before obtaining IP address
  * GOAL: save dynamically assigned IP address when switching to static
  * limit maxResponseDelay for ListIdentity Requests to 2000 ms
  * added API function opener_getVersion() to retrieve current version
  * added API functions CIP_getIdentity() & CIP_setIdentity() to manipulate Identity attributes
    (replaces  setDeviceSerialNumber())
  * GOAL: updated API to newest version

### V1.3.0 (2015-08-20)
  * GOAL: added platform files for GOAL
  * added DLR Object dor DLR Ring Nodes
  * added Ethernet Link attributes 4 "Interface Counters" & 5 "Media Counters"
  * added Ethernet Link service "Get_and_Clear"
  * added QoS object (attributes 4, 5, 6, 7, 8)
  * apply configured priories to all connections
  * fixed response of Ethernet Link service "GetAttibuteAll"
  * added TCP/IP Interface attribute 13 "Encapulation Timeout"
  * added Encapsulation Inactivity Watchdog to check all TCP connections
  * made TCP/IP Interface attributes 5 "Interface Configuration" & 6 "Host Name" settable
  * fixed response of Connection Manager class service "GetAttributeAll"
  * fixed check of Sequence Id for Sequenced Address Items

### V1.2.0 (2014-08-26)
  * added Connection Manager service "Large Forward Open"
  * RIN32M3: updated platform to support new BSP

### V1.1.0 (2014-03-13)
  * send out Response to Identity Object service "Reset" before resetting
  * added Ethernet Link attribute 10 "Interface Lable"
  * added support for multiple instances of Ethernet Link class
    (needed for devices with multiple interfaces)
  * RIN32M3: added platform files for Renesas RIN32M3

### V1.0.0 (2013-11-20)
  * TCP/IP Interface attribute 3 "Configuration Control" is settable
    (choice of IP address assignment)
  * fixed O2T Connection size check for connections with Run/Idle Header
  * use correct Connection Manager  errors for wrong connection sizes
  * fixed checking of Electronic Key in compatibility mode
  * removed unimplemented Connection Manager service "GetConnectionOwner"
    (Redundant Owner Connections are not supported)
  * Encap: Fixed error word for multiple Register Session Request on the same socket
